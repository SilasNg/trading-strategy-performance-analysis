# Trading Strategy Performance Analytics

## Overview

This project analyses the performance of a day trading strategy using Python and Microsoft Excel.

The objective was to identify factors influencing strategy performance and discover conditions associated with higher expectancy.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Microsoft Excel

## Analysis Performed

Python: 
- Data cleaning
- Exploratory data analysis
- Data visualisation
- Performance evaluation

Excel:
- KPI analysis
- Strategy breakdown

## Key findings

- Strategy achieved positive expectancy despite a 38% winrate.
- 15-minute HTF FVG setups outperformed 1-hour setups.
- 0.382-0.618 OTE zones produced stronger results.
- Short trades slightly outperformed long trades.
